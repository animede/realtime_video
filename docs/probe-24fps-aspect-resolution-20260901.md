# 24fps自由アスペクト比プローブ（2026-09-01）

環境: RTX PRO 6000 Blackwell、LTX-2.5 `nvfp4-fast`、a2v、121フレーム、8 steps、upscaleなし、同一画像・prompt・seed。実再生尺は約5.041秒。

## 結論

24fpsは512×288限定ではない。同程度の画素数なら3:2、7:5、2:3縦、9:16縦のすべてがE2E 0.83〜0.86xで安定してリアルタイム内に収まる。横型は480×320、縦型は320×480または288×512が実用候補。
